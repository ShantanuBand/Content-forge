# ContentForge 🚀

ContentForge is a full-stack AI-powered content creation platform that allows users to generate, save, edit, and manage content drafts easily.

---

## Features

- Generate AI-based content from a topic
- Save drafts to MongoDB
- View latest drafts (limited to 6 for clean UI)
- Read full draft on a separate page
- Edit and delete drafts
- Modern, responsive UI

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- React Router
- Axios
- React Markdown
- Custom CSS

### Backend
- Node.js
- Express.js
- MongoDB (Atlas)
- Mongoose
